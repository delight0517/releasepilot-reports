## 2026-09-17 사용자 요청 (보존)
- 앱 개발 대행 서비스: 얼리 런칭 건당 출시까지 35,000원.
- 기존 작업을 보기 좋게 보여주는 포트폴리오, 모바일에서도 읽기 쉽고 직관적인 상담 흐름.
- 앱을 모르는 고객도 제공 가능한 일을 이해하고 연락처/오픈 카카오톡 등으로 요청 가능.
- 개인 포트폴리오를 장기적인 개발자 등록·서비스·견적 매칭 플랫폼과 연결.
- 실제 앱 기능을 근거로 안내하고, 가상의 본인과 상담할 수 있는 AI 상담으로 확장.
- Mac/Windows 모두 같은 저장소에서 수정. 프로젝트별 작은 단계, 검증 후 자동 진행.

## 이어서 완료할 항목
- [ ] 서비스 페이지 공개 배포 후 URL/모바일/이메일 전송 실사용 확인.
- [ ] 상담 때 기능·수정 범위·일정·출시 방식 문서 합의 및 제3자 실비 발생 여부 사전 안내. 특정 기능 제외나 추가요금 정책을 임의 확정하지 않음.
- [ ] 실제 출시 링크/스토어 상태/기능별 실행 증거를 앱별로 새로 검증.
- [ ] 오픈 카카오톡/전화번호는 소유자가 제공한 공개용 값 확인 후 추가.
- [ ] 상담 수신 백엔드/메일 수신 확인 및 응답 운영. 현재는 직접 전송 이메일만 제공.
- [ ] 개인정보 허용 목록과 승인된 가격·가치관 데이터로 AI 상담 연결(별도 프로젝트).
- [ ] 개발자 계정 등록, 공개 서비스 프로필, 견적·요청 매칭, 거래 기능(후속 단계).

이 페이지는 등록 완료/서버 접수/자동 상담을 가장하지 않는다. 초안 내용은 페이지에서 외부 API에 보내거나 localStorage에 저장하지 않는다.
