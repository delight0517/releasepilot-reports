# 네이버 검색 노출 설정 가이드 (초보용, 터미널 몰라도 됨)

이 문서는 `about/index.html`(웹 명함)과 `index.html`(리포트 허브) 등 이
사이트가 네이버 검색 결과에 뜨게 만들기 위해 **rogan님이 딱 한 번, 네이버
계정으로 로그인해서** 직접 해야 하는 설정을 순서대로 안내합니다. 코드 쪽
준비(robots.txt, sitemap.xml, 검증 태그 자리)는 이미 다 끝나 있고, 아래
단계로 발급받는 값 하나만 파일 두 곳에 붙여넣고 커밋/push하면 됩니다.

예상 소요 시간: 10~15분. 색인 반영까지는 며칠~몇 주 걸릴 수 있습니다(네이버
쪽 사정이라 저희가 앞당길 수 없음).

---

## 0. 미리 알아둘 것

- "네이버 서치어드바이저"는 네이버가 운영하는 무료 도구로, 내 사이트를
  네이버 검색 로봇(Yeti)에게 공식적으로 알리는 창구입니다.
- 사이트 소유를 증명하는 방법은 여러 가지가 있는데, 여기서는 가장 간단한
  **"HTML 태그" 방식**을 씁니다 — 발급받은 코드 한 줄을 페이지에 붙여넣기만
  하면 됩니다(파일 업로드 방식보다 쉬움).

---

## 1. 네이버 서치어드바이저 접속 & 사이트 등록

1. 브라우저에서 https://searchadvisor.naver.com 접속.
2. 평소 쓰는 네이버 계정으로 로그인.
3. 상단 메뉴에서 "웹마스터도구" 클릭 (처음이면 "사이트 등록" 버튼이 바로
   보일 수도 있습니다).
4. "사이트 등록" 입력란에 다음 주소를 정확히 입력:
   `https://delight0517.github.io/releasepilot-reports/`
   (맨 끝 슬래시까지 포함해서 입력하는 걸 권장)
5. "추가" 또는 "등록" 버튼 클릭.

## 2. 소유 확인 — HTML 태그 방식으로 검증값 받기

1. 사이트 등록 직후 "소유 확인" 화면이 뜹니다. 여러 방식 중
   **"HTML 태그"** 탭(또는 "HTML 태그 복사" 옵션)을 선택.
2. 화면에 아래처럼 생긴 코드 한 줄이 나타납니다:

   ```html
   <meta name="naver-site-verification" content="abcdef1234567890...">
   ```

3. 큰따옴표 안의 값(`abcdef1234567890...` 부분)만 복사해두세요.
4. 이 저장소에서 다음 두 파일을 열어서, 이미 넣어둔 placeholder 줄을 찾습니다:
   - `about/index.html`
   - `index.html`

   두 파일 모두 `<head>` 안에 이미 이렇게 되어 있을 것입니다:

   ```html
   <meta name="naver-site-verification" content="여기에_나중에_채울_값">
   ```

5. `"여기에_나중에_채울_값"` 부분을 3번에서 복사한 실제 값으로 바꿔서
   저장합니다. (텍스트 에디터로 직접 고치거나, 다음 세션에게 "네이버
   검증값 붙여넣어줘, 값은 ○○○○야"라고 말해도 됩니다.)
6. 파일을 커밋하고 push합니다 (GitHub Pages는 push 후 보통 1~2분 안에
   반영됩니다).
7. push가 반영된 걸 확인한 뒤, 네이버 서치어드바이저 화면으로 돌아가
   "소유확인" 버튼을 클릭. 성공하면 "소유 확인이 완료되었습니다" 메시지가
   뜹니다.

   - 만약 실패하면: push가 실제로 GitHub Pages에 반영됐는지(브라우저에서
     `https://delight0517.github.io/releasepilot-reports/about/` 접속 →
     페이지 소스 보기 → `naver-site-verification` 줄이 실제 값으로
     바뀌었는지) 먼저 확인 후 다시 시도하세요.

## 3. 사이트맵 제출

1. 서치어드바이저 왼쪽 메뉴에서 "요청" → "사이트맵 제출" (또는 "수집" →
   "사이트맵 제출", 네이버 쪽 메뉴 이름이 가끔 바뀝니다 — "사이트맵"이 들어간
   메뉴를 찾으면 됩니다) 클릭.
2. 입력란에 다음 값만 입력 (전체 주소가 아니라 사이트맵 파일명만):
   `sitemap.xml`
3. "확인" 또는 "제출" 클릭.
4. 상태가 "성공"으로 바뀌면 완료. (바로 안 바뀌어도 정상 — 시간이 걸릴 수
   있습니다.)

## 4. 색인 요청 (웹페이지 수집 요청)

사이트맵만 제출해도 언젠가 자동으로 수집되지만, 빠르게 반영하고 싶으면
페이지별로 직접 요청할 수 있습니다.

1. 왼쪽 메뉴에서 "요청" → "웹페이지 수집" 클릭.
2. 수집을 원하는 페이지 주소를 한 줄씩 입력, 예:
   ```
   https://delight0517.github.io/releasepilot-reports/
   https://delight0517.github.io/releasepilot-reports/about/
   https://delight0517.github.io/releasepilot-reports/portfolio/
   ```
3. "확인" 클릭.
4. 하루에 요청할 수 있는 횟수에 제한이 있으니(보통 페이지당 하루 몇 회), 안
   되면 다음날 다시 시도하면 됩니다.

## 5. 다 끝난 뒤 확인하는 법

- 며칠 지난 뒤 네이버 검색창에 `site:delight0517.github.io` 를 검색하면
  색인된 페이지 목록이 보입니다.
- "김근후" 같은 실제 이름/키워드로 검색했을 때 뜨는지는 네이버 검색
  알고리즘 판단 영역이라 저희가 보장할 수 없습니다 — 서치어드바이저에
  등록·수집 요청까지가 저희가 할 수 있는 최대치입니다.

## 참고 — 이미 코드로 준비되어 있는 것

- `robots.txt` — 네이버 봇(Yeti) 포함 모든 크롤러 허용, sitemap.xml 위치
  명시.
- `sitemap.xml` — 공개 페이지 전체 등록.
- `about/index.html`, `index.html` — Open Graph/Twitter Card 메타 태그,
  `naver-site-verification` placeholder.

이 문서에 나온 1~4단계(네이버 계정 로그인이 필요한 부분)만 rogan님이 직접
하면 됩니다.
