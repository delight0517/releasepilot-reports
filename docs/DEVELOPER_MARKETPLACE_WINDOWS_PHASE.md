# 개발자 견적 플랫폼 — Windows 단계

빌드: 20260917.2

`app-studio/marketplace.html`은 서버와 iPhone에 의존하지 않는 로컬 미리보기다. 고객 요청과 개발자 프로필의 최소 입력 형식을 정하고, 브라우저 `localStorage`에 초안만 저장한다. 외부 전송·계정·결제·실제 매칭은 연결하지 않는다.

## 검증 기준

- 모바일 폭에서도 요청/프로필 폼이 세로로 읽힌다.
- 민감정보를 받지 않는 안내가 화면에 표시된다.
- 두 폼 모두 필수값 검증 후 초안을 저장하고 목록에 렌더링한다.
- `clear`로 현재 브라우저 초안을 삭제할 수 있다.

## 다음 서버 단계

계정별 권한, 영구 저장, 요청-견적 연결, 수정·삭제, 접수 확인을 API에 연결한다. 이 페이지의 “저장” 문구는 서버 접수가 아니다.
