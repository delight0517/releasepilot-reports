Privacy Policy

Effective August 26, 2026. (한국어 버전은 아래에 있습니다 / Korean version below.)

This policy explains how personal data is collected and used by the applications provided by vivid_wave / Geungho Lee (the "Developer"), including Vintage Pomodoro (Windows), PomodoroCage / Auto Pomodoro (iOS), RiseSync, 사계기록 (Harugirok), Brainwire, and 35Closer (collectively, the "Apps").

1. Information We Collect

The Apps process only the minimal information below, and only on the user's own device. No personal data is transmitted to any server operated by the Developer.

  • Collected data: app usage/session history, focus/break timer session records, and timer/lock settings — all stored only on the user's device (Windows local app storage, iOS Documents, or Android internal storage).
  • External transmission: None. Some apps (e.g. cross-device Pomodoro sync) only communicate with a personal Mac server on the user's own local Wi-Fi network that the user explicitly configures; that communication never leaves the local network.

2. Purpose of Use

  • Running the focus/break timer and displaying today's session statistics.
  • Syncing timer state across a user's own devices (e.g. Mac/iPhone), where applicable.
  • Optional break-lock features (e.g. Vintage Pomodoro's strict lock) that keep the app active during a scheduled break — this setting is stored locally and never leaves the device.

3. Storage and Deletion

All data is stored only on the user's device and is removed when the app is uninstalled. The Developer does not collect or retain any personal data on any server.

4. Third-Party Sharing

The Developer does not share user personal data with any third party.

5. Your Rights

You may uninstall any app at any time to remove all data stored on your device. For any other questions, contact the email address below.
