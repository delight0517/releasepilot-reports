01

제작물 — ArtStation 최신순

ArtStation에 올라온 작업입니다. 이 그리드는 assets/artstation/works.json을 읽어 렌더링되며, 매월 ArtStation과 동기화됩니다.

전체 작업은 ArtStation 프로필에서 확인할 수 있습니다.

02

제작 프로세스

Modeling → Texturing → Lighting/Presentation → Revision — 실제 문제를 풀면서 익힌 게임 아트 제작 흐름.

S1

형태 개발 · 3ds Max

게임 오브젝트를 모델링 대상으로 선정, 실루엣 수정 → 형태 개선 → 색감 단계 개선으로 단계적 발전.

S2

핸드페인팅 · Substance

Paint Layer 기반 핸드페인팅, Polygon Fill 영역 작업. 하이트맵·러프니스로 입체감.

S3

문제 해결

뒷면 페인트 번짐 — Camera Occlusion / Backface 설정 탐색. 브러시 투명도·레이어 수정 워크플로우.

S4

라이팅 · 연출

스포이드 색상 추출, 환경광·HDRI 방향 조절. 배경 이미지와 오브젝트 색 조화 확인.

S5

출력 · 재활용

텍스처 출력과 재활용 방법 탐색 — 게임 안에서 이 오브젝트가 어떻게 보이는가까지 판단.

03

3D 작업물 아카이브

스케치·모델링·렌더 과정이 섞인 원본 아카이브입니다. 이미지를 클릭하면 크게 볼 수 있습니다.

원본: 본인 제공 Notion 3D 작업물 문서(자체 호스팅).

Stylized 3D Artist / Hand-painted Game Artist

Visual Development / World-building

캐릭터·소품·공간·색채·조명·이야기를 하나의 경험으로 연결하려는 경향. 서울 도시 누아르, 웹툰식 공간, 현대 도시의 생활감처럼 하나의 장면 전체를 설계하는 방식에 관심이 있습니다. 현재는 3D 제작 능력을 기반으로 Visual Development 역량을 확장하고 있는 단계입니다.

Growing

Game / Interactive Content Planner

기능을 나열하지 않고 단계로 분해하는 사고 — 사용자 문제 → 발생 조건 → 사용자 행동 → 개입 → 피드백 → 다음 행동. 행동 시스템 설계 때도 작동 조건·단계별 행동·완료 확인·예외 상황·환경 변화·출력 형식까지 나눠 설계한 사례가 있습니다. interaction flow와 rule system을 만드는 사고방식에 가깝습니다.

Edge

AI-assisted Creative Designer

AI를 답을 받는 도구가 아니라 리서치·기획·검증 파트너로 반복 투입합니다. 문제 정의 → 자료 조사 → 아이디어 생성 → 반론 → 개선 → 구조화 → 다시 제작, 이 과정을 AI와 반복합니다. 복잡한 기능 요청의 우선순위화, 사용자 행동별 반응 설계 프롬프트 시스템 제작이 여기 해당합니다.

Extension

아트워크 → 의류/굿즈 제작

컨셉아트에서 쌓은 형태·색채·실루엣 감각은 캔버스 밖으로 확장됩니다. 프린트용 그래픽 분리, 컬러 매칭, 목업 프레젠테이션까지 같은 워크플로우로 처리합니다. 실제 판매 중: Vivid_Wave_shop (마플샵).
