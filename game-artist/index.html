01 · 가장 직접적인 연결점

Junior 3D Game Artist — Prop / Environment

3ds Max 모델링부터 Substance 3D Painter 텍스처링까지, 실제로 다룬 제작 단계 중심으로 정리.

Modeling

3ds Max — 형태 개발

게임 오브젝트(검 등)를 모델링 대상으로 선정해 형태를 분석하고, 실루엣 수정 → 형태 개선 → 색감 단계 개선 순으로 결과물을 단계적으로 발전시키는 방식으로 작업했습니다.

Texturing

Substance 3D Painter — 핸드페인팅 워크플로우

  • Paint Layer 기반 핸드페인팅, Polygon Fill을 이용한 영역 작업
  • 뒷면까지 페인트가 묻는 문제 해결 — Camera Occlusion / Backface 설정 탐색
  • 브러시 투명도 조절, 레이어 및 기존 페인팅 결과 수정
  • 스포이드로 색상 추출, 환경광·HDRI 방향 조절
  • 배경 이미지와 오브젝트 색 조화 확인, 텍스처 출력 및 재활용 방법 탐색

즉 Modeling → Texturing → Lighting/Presentation → Revision으로 이어지는 게임 아트 제작 흐름을 실제 문제를 풀면서 익히는 중입니다.

02 · 방향성

Stylized 3D Artist / Hand-painted Game Artist

사실적 재현보다 색감·실루엣·분위기·세계관의 조화를 우선한다.

Substance Painter를 포토샵처럼 활용해 직접 색을 그리고 수정하는 Hand Painting 방식에 관심을 두며, 배경 이미지와 조명까지 설정해 "게임 안에서 이 오브젝트가 어떻게 보이는가"를 판단하려 합니다. 형태 + 색 + 분위기 + 세계관을 함께 디자인하는 Stylized Game Art와 방향이 맞습니다.

03 · 확장 방향 (현재는 기반을 쌓는 단계)

Visual Development / World-building

캐릭터·소품·공간·색채·조명·이야기를 하나의 경험으로 연결하려는 경향.

서울 도시 누아르, 웹툰식 공간, 현대 도시의 생활감처럼 하나의 장면 전체를 설계하는 방식에 관심을 보여왔습니다. 다만 현재 시점에서는 3D 제작 능력을 기반으로 Visual Development 역량을 확장하고 있는 단계로 표현하는 것이 정확합니다.

04 · 함께 발전시킬 역량

Game / Interactive Content Planner

기능을 나열하지 않고 단계로 분해하는 사고 — 시스템 문서/프로토타입이 붙으면 더 강해지는 영역.

사용자 문제 → 발생 조건 → 사용자 행동 → 개입 → 피드백 → 다음 행동, 이런 식으로 단계를 나누는 경향이 있습니다. 행동 시스템을 설계할 때도 작동 조건·단계별 행동·완료 확인·예외 상황·환경 변화· 출력 형식까지 나눠 설계한 사례가 있습니다 — interaction flow와 rule system을 만드는 사고방식에 가깝습니다.

05 · 차별점

AI-assisted Creative Designer

AI를 답을 받는 도구가 아니라 리서치·기획·검증 파트너로 반복 투입.

문제 정의 → 자료 조사 → 아이디어 생성 → 반론 → 개선 → 구조화 → 다시 제작, 이 과정을 AI와 반복합니다. 복잡한 기능 요청을 우선순위화하거나 사용자 행동에 따라 다른 반응을 설계하는 프롬프트 시스템을 만드는 방식이 여기 해당합니다.
