# Journey 사막 월드 개발 기록

정적 포트폴리오용 이미지 중심 개발 일지입니다. 공개할 캡처 사본은 `assets/`에 두고, 항목은 `entries.json`에 오래된 순서대로 추가합니다.

각 항목은 `date`, `title`, `status`, `label`, `image`, `alt`, `text`를 가집니다. `status`는 `reference`, `wip`, `verified`, `rejected` 중 하나로 기록합니다. 시각적으로 미완성인 캡처를 완성작처럼 설명하지 말고, 실제 엔진 캡처·메커니즘 검증·아트 상태를 구분합니다.

원본 참고 이미지와 QA 캡처는 Journey 프로젝트에 보존하고, 여기에는 승인된 대표 이미지 사본만 둡니다. 게임 저장 파일, 로그, 사용자 대화 화면, 다른 프로젝트의 자산은 넣지 않습니다.
