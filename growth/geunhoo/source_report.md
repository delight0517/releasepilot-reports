**목표:** 인스타그램에서 개인 브랜드와 영향력을 만들면서, 게임 아트·콘텐츠 제작 관련 취업 및 협업 기회로 연결

## 1. 결론

현재 플랜은 **취업용 포트폴리오 유입 전략으로는 7.5/10**, **인스타그램 인플루언서 성장 전략으로는 5.5/10** 정도다.

핵심 포지셔닝인 `3D Game Artist × AI-assisted Creative Designer`는 전문성과 차별성이 있다. 하지만 이 문구와 현재 콘텐츠 기획은 채용 담당자가 이해하기에는 좋지만, 인스타그램에서 처음 만난 사람이 즉시 멈춰 보고 공유할 만큼 쉽고 감정적인 메시지는 아니다.

따라서 방향 자체를 버릴 필요는 없다. 다만 다음처럼 바꿔야 한다.

> **전문성은 3D 게임 아트에 고정하고, 콘텐츠는 일반 시청자가 이해할 수 있는 변화·실패·발견·이야기로 포장한다.**

한 문장으로 평가하면:

> 지금 플랜은 "내가 무엇을 할 수 있는지 증명하는 포트폴리오 계획"에 가깝고, "사람들이 계속 보고 싶어 하는 인스타그램 크리에이터 계획"으로는 시청자 관점의 설계가 더 필요하다.

## 2. 인스타그램 관점에서 잘 작동하는 부분

### 2-1. 시각적 변화가 있는 주제가 강하다
실루엣에서 완성으로 가는 과정, 빈 텍스처에서 완성되는 과정, Before/After는 인스타그램 릴스에 적합하다. 첫 화면과 마지막 화면의 차이가 명확해 짧은 영상에서도 결과를 이해하기 쉽다.

### 2-2. 원본 제작 과정이 신뢰를 만든다
직접 만든 모델링·텍스처링·조명·수정 과정을 보여주면 단순 이미지 생성물이나 작업 결과물 모음과 구별된다. Meta도 최근 창작자가 직접 만든 원본 콘텐츠와 재공유 기능을 강화하는 방향을 발표했다. 콘텐츠를 직접 제작하고, 다른 사람이 공유하고 싶을 만한 이유를 넣는 것이 유리하다.

### 2-3. 3D 게임 아트는 좁지만 명확한 시장이다
대중적인 팔로워 수를 빠르게 모으는 주제는 아닐 수 있지만, 게임 개발자·아트 지망생·3D 툴 사용자·채용 담당자에게는 전문성이 바로 전달된다. 영향력의 양보다 협업·채용으로 이어지는 질을 중시한다면 좋은 출발점이다.

### 2-4. AI 작업 과정은 차별화 가능성이 있다
AI를 단순히 결과물을 만드는 도구로 보여주는 대신 질문·반론·검증·재구조화 과정으로 보여주면 김근후님만의 작업 방식이 생긴다. 단, AI 대화 자체가 주인공이 되면 3D 아트 계정이 아니라 프롬프트 계정으로 인식될 수 있으므로 항상 최종 결과물과 연결해야 한다.

## 3. 현재 플랜의 마케팅 약점

### 3-1. 타깃이 너무 많다
게임사, 영상 채용 담당자, 앱 관심층, 공연 관계자, 글 독자층을 한 계정에 모두 넣으면 계정의 첫인상이 흐려진다. 계정 하나를 유지하는 것은 괜찮지만, 모든 주제를 같은 우선순위로 보이게 하는 것은 좋지 않다.

인스타그램에서는 게시물 하나가 새로운 사람에게 먼저 노출될 수 있다. 그 사람이 게시물을 보고 프로필로 왔을 때, "이 계정은 누구를 위한 계정인가?"를 3초 안에 이해해야 팔로우로 이어진다.

### 3-2. 현재 문구가 채용용 언어에 가깝다
`AI-assisted Creative Designer`, `문제 구조화`, `시스템 사고`, `반복 개선`은 포트폴리오 설명에는 적합하지만, 릴스 첫 문장으로는 추상적이다.

인스타그램에서는 다음처럼 구체적이고 시각적인 문장이 더 강하다.
- 추상적: `AI와 함께 창작 문제를 구조화합니다.` → 인스타그램형: `AI가 만든 이 형태가 별로였던 이유`
- 추상적: `3D 게임 아트 제작 과정을 공유합니다.` → 인스타그램형: `게임 속 낡은 상자를 3단계로 다시 만들었습니다.`

### 3-3. "보여주는 콘텐츠"는 있지만 "공유할 이유"가 약하다
작업 과정을 보는 것과 친구에게 보내는 것은 다르다. 릴스는 완성도만으로 충분하지 않고, 시청자가 다음 행동을 할 이유가 필요하다.

공유·저장을 유도할 수 있는 방향: 3D 아트 지망생이 참고할 수 있는 체크리스트 / 초보자가 자주 하는 실수 / Before·After에서 무엇을 고쳤는지 맞히는 장면 / 게임 아트 작업자라면 공감할 만한 실패 / "이전 버전과 새 버전 중 무엇이 나은가?" 같은 선택형 질문.

### 3-4. 기존 5개 기둥은 운영 부담이 크다
주 3회 업로드만 해도 5개 기둥이 번갈아 나오면 각 주제의 표본이 너무 적어진다. 어느 주제가 성장 가능성이 있는지 판단하기 전에 콘텐츠가 흩어진다.

초기 8주 동안은 다음 정도로 압축하는 것이 좋다.

| 비중 | 기둥 | 역할 |
| --- | --- | --- |
| 55% | 3D 게임 아트 | 전문성·채용·협업 증명 |
| 20% | 제작 과정과 실패/개선 | 시청 지속·저장·공유 |
| 15% | AI 작업 방식 | 차별화·대화 소재 |
| 10% | 편집·개발·연기·음악 | 인간적인 확장성 |

확장 콘텐츠는 별도 계정으로 당장 분리할 필요는 없지만, 프로필 상단 고정 게시물과 하이라이트에서 보조 영역으로 처리하는 편이 낫다.

## 4. 인스타그램용 전략으로 수정한 포지셔닝

내부 포지셔닝: `3D Game Artist × AI-assisted Creative Designer`
외부에서 보이는 콘텐츠 문장: `게임 속 오브젝트가 완성되는 과정을 보여주는 사람`
차별화 문장: `AI에게 답을 받는 사람이 아니라, AI와 함께 더 나은 게임 아트를 실험하는 사람`

이렇게 하면 전문 직무는 유지하면서도 일반 이용자가 이해할 수 있는 시각적 약속이 생긴다.

## 5. 콘텐츠 포맷별 실행안

### A. 발견용 릴스: 새로운 사람에게 도달
목적은 팔로워가 아닌 비팔로워의 시청과 공유다.
권장 구조: 0~1초 완성 결과/문제 장면 → 1~3초 무엇을 바꾸는지 제시 → 3~12초 변화 과정 → 마지막 2~3초 완성 결과+한 줄 결론.
예시: `이 상자가 게임에서 장난감처럼 보였던 이유` — 형태 수정 → 텍스처 변화 → 조명 비교 → 최종 결과.

### B. 저장용 캐러셀: 전문성 축적
릴스만으로는 작업 설명이 부족하다. 캐러셀 주제: 게임 프롭을 만들 때 확인하는 5가지 / 핸드페인팅 텍스처의 레이어 구조 / 모델링 초안에서 고친 부분 3가지 / AI를 사용할 때 검증하는 질문 목록. 첫 장은 결과물보다 문제를 크게 쓰는 것이 좋다.
예시: `왜 이 모델은 완성했는데도 게임 오브젝트처럼 안 보일까?`

### C. 관계 형성용 스토리
스토리는 도달보다 관계와 신뢰를 만든다. 오늘 수정한 부분 / 작업 중 막힌 문제 / 팔로워 투표(A안 vs B안) / 다음에 만들 오브젝트 선택 / 작업실·툴·실패한 시안.

### D. 전환용 프로필·고정 게시물
프로필 방문자가 포트폴리오로 이동하기 전에 확인해야 할 3가지: 대표 완성작 / 제작 과정과 수정 능력 / 연락·포트폴리오 링크.
고정 게시물 3개 권장: `나는 어떤 3D 아티스트인가` / `대표 작업 Before/After` / `작업 과정과 포트폴리오 링크`.

## 6. 릴스 아이디어를 인스타그램형으로 개선

| 기존 아이디어 | 개선된 훅 | 시청자 행동 |
| --- | --- | --- |
| 실루엣→완성 | `이 실루엣이 게임 오브젝트가 되기까지` | 끝까지 시청 |
| 텍스처 타임랩스 | `색을 예쁘게 칠해도 게임에서 망하는 이유` | 저장 |
| AI에게 반박시키기 | `AI가 제안한 디자인을 그대로 쓰지 않은 이유` | 댓글·공유 |
| Before/After | `처음엔 괜찮아 보였는데, 이 부분을 고쳤습니다` | 비교 시청 |
| 제작자의 사고 과정 | `이 조명을 바꾸자 오브젝트의 용도가 달라졌습니다` | 시청·팔로우 |

핵심은 "내가 무엇을 했다"보다 "시청자가 무엇을 발견할 수 있는가"를 앞에 두는 것이다.

## 7. 인스타그램 기능을 활용한 실험

### Trial Reels
Instagram의 Trial Reels는 콘텐츠를 먼저 비팔로워에게 보여주고, 약 24시간 뒤 조회·좋아요·댓글·공유 등의 지표를 확인할 수 있게 한다. 성과가 좋으면 전체 공개하거나 자동 공유 설정을 사용할 수 있다. 주제가 넓은 계정에서 3D 아트, AI, 편집 콘텐츠를 실험할 때 특히 유용하다. (출처: Meta의 Trial Reels 안내)

### Repost와 공유성
2025년 Instagram은 공개 릴스와 게시물을 다시 공유하는 Repost 기능을 발표했고, 재공유된 콘텐츠가 공유자의 팔로워에게 추천될 수 있다고 설명했다. 따라서 "좋아요를 눌러주세요"보다 "이 문제를 겪는 사람에게 보내주세요"에 가까운 공유 가치를 설계해야 한다. (출처: Meta의 Instagram Repost 안내)

### 원본 제작
제작 화면, 손으로 직접 수정한 과정, 실제 결과물을 계속 축적해야 한다. 다른 사람의 작업물을 단순히 모아 소개하는 계정이 아니라 "김근후가 만들고 판단한 것"이 보이는 계정이어야 한다.

## 8. 8주 테스트 계획

### 주간 업로드
릴스 2개(발견용·공유용) / 캐러셀 1개(저장용·전문성) / 스토리 4~7일(투표·진행 상황·관계 형성).
주 3회 피드 업로드는 유지하되, 매번 다른 직무를 홍보하지 않는다. 한 주의 콘텐츠가 같은 작업 또는 같은 질문을 여러 형식으로 확장하도록 만든다.

### 테스트 변수 (한 주에 하나만 비교)

| 실험 | A | B |
| --- | --- | --- |
| 첫 장면 | 완성작 먼저 | 문제 장면 먼저 |
| 말투 | 작업 설명 | 시청자 질문 |
| 길이 | 10~15초 | 20~30초 |
| 결말 | 완성 결과 | 실패와 수정 결과 |
| CTA | 포트폴리오 확인 | 친구에게 공유/저장 |

## 9. 성과 측정 기준

팔로워 수만 보면 방향을 잘못 잡을 수 있다.

- **발견**: 비팔로워 도달 비율 / 릴스 조회수 / 평균 시청 시간 / 완주율(유지율)
- **콘텐츠 가치**: 공유 수 / 저장 수 / (공유+저장)÷도달 / 댓글의 구체성
- **전환**: 릴스에서 발생한 신규 팔로워 / 프로필 방문 수 / 프로필 방문 대비 팔로우 전환율 / 링크 클릭 수 / 포트폴리오 문의 수

8주 후에는 조회수가 가장 높은 콘텐츠보다, **비팔로워 도달·공유·신규 팔로워·프로필 방문을 동시에 만든 포맷**을 주력으로 남긴다.

## 10. 예상 리스크와 대응

1. **전문적이지만 재미가 없다** → 작업 설명을 시작하지 말고, 실패·비교·의외의 결과를 첫 장면에 둔다.
2. **AI 계정으로 오인된다** → AI 화면은 전체 영상의 일부만 사용하고, 반드시 김근후님의 모델링·텍스처링·판단·수정 결과를 중심에 둔다.
3. **다양한 재능이 계정 신뢰를 분산시킨다** → 8주 동안 3D 아트를 메인으로 고정하고, 편집·개발·연기·음악은 스토리나 월 1~2회 확장 콘텐츠로 제한한다.
4. **채용 담당자와 일반 팔로워 모두에게 애매해진다** → 릴스는 쉽게, 캐러셀과 고정 게시물은 전문적으로 만든다. 하나의 콘텐츠에 두 타깃을 모두 만족시키려 하지 않는다.

## 11. 최종 권고

이 플랜은 실행할 가치가 있다. 단, 이름을 "인스타그램 인플루언서 플랜"으로 부르기보다 첫 8주는 **3D 게임 아트 기반 크리에이터 검증 캠페인**으로 운영하는 것이 정확하다.

우선순위:
1. 프로필 문장을 쉬운 말로 수정
2. 3D 아트 릴스 6개를 먼저 제작
3. 각 릴스에 발견·공유·저장 중 하나의 목적만 부여
4. Trial Reels가 제공되는 계정이면 비팔로워 테스트에 사용
5. 캐러셀과 스토리로 전문성과 관계를 보강
