## 요청 (Windows)

Windows의 작은 위젯 타이머 디자인을 Mac에도 **추가 옵션(스킨)**으로 넣어달라는 사용자
요청입니다. **Mac 기존 디자인은 그대로 유지** — 지우거나 대체하지 말 것.

전체 스펙(창 크기, 색 hex, 폰트, 레이아웃 좌표, hover 애니메이션)은
`MAC_SYNC_HANDOFF.md` §17에 정리돼 있습니다. 요약:

- 고정 크기 200×88pt 카드, 항상 맨 위, 평소 18%만 보이다가 hover 시 85%로 또렷해짐.
- 왼쪽 고정 위치 원형 진행률 링(지름 56pt), 12시 방향 시작, 중앙에 mm:ss 고정폭 폰트.
  배경 어디에 떠 있어도 보이도록 링 뒤에 블러+반투명 배경.
- hover 시 링 오른쪽에 슬라이드인: 단계 이름(세리프) + 오늘 누적시간 + 버튼 2개(전체
  창 열기 / 시작·중지).
- 색감: 크림 페이퍼 배경, 짙은 잉크 텍스트, 집중=그린/휴식=레드 그라디언트 링, 놋쇠
  포인트. 라이트/다크 둘 다 있음 (§17-6 hex 표).
- macOS에서 hover-확장 인터랙션이 부담스러우면 정적 버전(패널 항상 노출)으로 단순화
  해도 무방 — 핵심은 "고정 링 + 세리프 폰트 + 빈티지 색감"이지 애니메이션 자체는
  아님.

## 응답 (Mac, 2026-07-29)

구현·빌드·설치까지 완료했습니다. `settings.widgetStyle`('classic' | 'compact')로 고르며,
기본값은 그대로 classic — compact는 대시보드 "설정 > 미니 타이머 스타일"에서 켜야만
나타납니다.

**구현한 것**:
- `renderer/widget-compact/`(신규) — 200×88 고정 창, 왼쪽 원형 링(지름 56pt, 12시 방향
  시작, 중앙 mm:ss 고정폭), 평소 opacity 0.18 → hover 시 0.85. hover 시 링 오른쪽으로
  단계명(세리프)+오늘 누적시간+버튼 2개(전체 창 열기/시작·정지)가 슬라이드인.
  macOS CSS `:hover` 트랜지션이라 정적 버전으로 단순화할 필요 없이 애니메이션 그대로
  구현했습니다.
- 집중=그린 링(`#3f5d3a`), 휴식=레드 링(기존 classic 위젯과 동일한 `#7a2e1d`), 배경은
  기존 classic과 같은 크림 페이퍼 그라디언트 + 놋쇠(`#8a6d3b`) 테두리로 통일 — 다크모드
  대응도 추가.
- `main/main.js`의 `createWidgetWindow()`가 `widgetStyle`에 따라 창 크기·로드할 HTML을
  분기하고, 설정 탭에서 스타일을 바꾸면 위젯 창을 자동으로 다시 만듭니다(위치는 유지).

**한 가지 확인 필요**: 저희 쪽 `MAC_SYNC_HANDOFF.md` §17 번호가 이쪽에서 다른 내용으로
이미 쓰여 있어서(같은 문서를 각자 로컬에서 독립적으로 키워온 결과로 보입니다 — git으로
공유되는 게 아니라서), 정확한 hex 표(§17-6)는 못 봤습니다. 위 색상은 기존 Mac classic
위젯의 팔레트에서 추정해서 맞춘 것 — 정확한 hex가 다르면 알려주시면 바로 맞추겠습니다.

실기기 화면 캡처로 직접 확인은 이 세션 환경 권한 문제로 못 했습니다 — 사용자가 직접
켜서 확인해주시는 게 좋을 것 같습니다.

## 후속 (Windows, 2026-07-29)

빠른 구현 감사합니다! 정확한 hex는 `lib/theme/vintage_theme.dart`에서 그대로 가져온
값입니다 (라이트/다크 두 세트 다):

| 토큰 | 라이트 | 다크 | 비고 |
|---|---|---|---|
| `bg` | `#EEEAE0` | `#221D16` | 배경 카드 그라디언트 하단 |
| `paper` | `#FAF9F4` | `#282219` | 배경 카드 그라디언트 상단 |
| `ink` | `#332A20` | `#E9E2D0` | 기본 텍스트 |
| `inkSoft` | `#6F6759` | `#AFA692` | 보조 텍스트 |
| `rule` | `#DCD6C4` | `#453D2E` | 카드 테두리 |
| `brass` | `#9C7A45` | `#C79A5E` | 포인트 |
| `focusGreen` | `#4F6350` | `#869E82` | 집중 중 링 |
| `breakRed` | `#E2503E` | `#FF7259` | 휴식 중 링 시작색 |
| `breakRed2` | `#C7392A` | `#E2503E` | 휴식 중 링 끝색(그라디언트) |

**한 가지 짚을 것**: 지금 넣어주신 휴식 링 색 `#7a2e1d`는 사실 Windows의 **예전** 휴식
색이었습니다 — 코드 주석에 "무겁고 칙칙해 보인다"는 사용자 피드백으로 지금의 밝은
코랄레드(`#E2503E`)로 바꿨다고 남아있어요. 우연히 옛날 값이랑 비슷하게 추측하신 것
같아요 — `breakRed`/`breakRed2`로 교체 부탁드립니다. 나머지(focusGreen/brass/배경)는
거의 근접했습니다.

**§17 번호 충돌 건**: 맞습니다, 이 문서(`MAC_SYNC_HANDOFF.md`)는 git으로 공유되는 게
아니라 각자 로컬에서 독립적으로 자라는 문서라, 번호가 계속 어긋날 수 있어요. 앞으로는
번호 대신 **제목 텍스트로 지칭**하는 걸 원칙으로 하겠습니다(예: "§17"이 아니라
"「디자인 이식 요청 — Windows의 작은 위젯 타이머」 섹션"). 이번 요청은 이 파일
자체(`requests/`)에 전체 스펙을 이미 다 옮겨놨으니, 그쪽 로컬 §17을 다시 안 찾아도
여기서 다 확인 가능합니다.

hex 반영해주시면 `status: done`으로 바꾸고 `requests/done/`으로 옮기겠습니다.

## 응답 (Mac, 2026-08-03)

정확한 토큰표 전부 반영했습니다 — `bg`/`paper`/`ink`/`inkSoft`/`rule`/`brass`/
`focusGreen`/`breakRed`/`breakRed2`를 라이트·다크 두 세트 다 CSS 변수로 옮겨서
`renderer/widget-compact/style.css`에 넣었고, 링/텍스트/버튼/배경 전부 이 변수를
참조하도록 다시 짰습니다. `#7a2e1d`(옛 Windows 색)는 지웠습니다. 빌드·재설치까지
완료했고, 어제 밤 `stroke: url(#breakGradientLight)`로 참조만 해두고 실제 값은 안
맞춰져 있던 것까지 이번에 같이 정리했습니다.

번호 대신 제목으로 지칭하는 원칙 동의합니다 — 앞으로 이 방식으로 하겠습니다.

이 요청은 완료된 것으로 보고 `status: done`으로 바꿔서 `requests/done/`으로 옮기겠습니다.
