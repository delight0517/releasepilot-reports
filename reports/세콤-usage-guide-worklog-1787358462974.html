01

개요 — 이 도구는 무엇을 위한 것인가

"세콤"은 사용자 개인의 쇼츠(유튜브 Shorts) 채널 운영을 자동화하는 개인용 파이프라인이다. 관심 있을 만한 소재를 모으고, 사용자가 노션에서 직접 승인한 것만 골라서, 영상 소스 확보 → AI 더빙(TTS) → 자동 조립(편집이 아니라 규칙대로 합성) → 유튜브 업로드까지 자동으로 진행한다.

가장 중요한 안전장치: 노션의 소스유형 값이 stock(라이선스 있는 스톡 영상) 또는 self_filmed(본인 직접 촬영)가 아니면, 파이프라인이 그 항목을 무조건 건너뛴다. 남의 영상을 그대로 재가공해서 올리는 건 유튜브 정책·저작권상 위험해서, 이번 버전에서는 이 기능 자체를 일부러 비활성화해뒀다.

02

핵심 사용 흐름 (완성됐을 때 기준)

1노션에 소재 올리기

사용자가 관심 있는 소재를 노션 데이터베이스에 넣고, 쓸 만한 것만 "상태=승인"으로 표시한다.

2동기화

notion_sync.js가 "승인"된 항목만 읽어온다.

3안전장치 통과 확인

source_gate.js가 소스유형을 확인 — stock/self_filmed가 아니면 여기서 걸러진다.

4더빙 + 자동 조립

tts_dub.js가 대본을 읽어 자동으로 목소리를 입히고, render.js가 영상+더빙+자막을 규칙대로 합쳐 세로 영상(1080×1920)을 만든다. 사람이 직접 자르고 붙이는 편집이 아니라 자동 합성이다.

5업로드

upload.js가 유튜브에 올린다(기본은 비공개로 올라가서 사람이 확인 후 공개 전환).

03

구성 파일 — 빠른 레퍼런스

notion_sync.js

노션 DB에서 승인된 항목을 읽어온다.

source_gate.js

저작권 안전장치. 소스유형이 stock/self_filmed가 아니면 무조건 스킵.

fetch_source.js / tts_dub.js / render.js / upload.js

영상 확보 → 더빙 → 자동 조립 → 업로드, 순서대로 실행되는 단계별 스크립트.

pipeline.js

위 단계를 한 번에 순서대로 돌리는 실행 명령.

PLAN.md

전체 기획서 — 요구사항 원문, 저작권 리스크 경고, 시중 도구 리서치 결과.

이 5가지를 순서대로 하셔야 실제로 돌아갑니다. 코드는 이미 다 준비돼 있어요.

  • ☐ 1. 노션 페이지를 데이터베이스로 바꾸기 — 지금은 그냥 글이 나열된 페이지라 자동화가 못 읽는다. 표(데이터베이스) 형태로 바꾸고 다음 칸을 만든다: 제목 / 소스URL / 소스유형(stock 또는 self_filmed만, 영어로 오타 없이) / 상태(후보·승인·렌더중·완료) / 대본(TTS로 읽을 텍스트) / 업로드일정.
  • ☐ 2. 노션 토큰 발급 — notion.so/my-integrations에서 새 통합 생성 → 토큰 복사. 중요: 1번 데이터베이스 우측 상단 "..." → Connections에서 방금 만든 통합을 반드시 연결해야 한다(빠뜨리면 나중에 404 에러).
  • ☐ 3. TTS(자동 더빙) 계정 만들기 — OpenAI 계정과 결제수단을 등록하고 API 키를 발급받는다(ElevenLabs로 바꾸고 싶으면 요청하면 된다).
  • ☐ 4. 유튜브 업로드 권한 받기 — 구글 클라우드 콘솔에서 "YouTube Data API v3"를 켜고 OAuth 데스크톱 클라이언트를 만든다. 그 다음 node scripts/youtube_auth.js를 직접 실행해서 로그인 승인을 해야 한다(이 단계는 대신 눌러줄 수 없다).
  • ☐ 5. 위 4개를 다 마치면 알려주기 — 발급받은 키들을 설정 파일에 채우고, 샘플 영상 3개로 실제 테스트를 한 번 돌려본다.
