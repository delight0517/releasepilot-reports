지금 바로 쇼츠 만들기 — 시작 키트

완전 자동 파이프라인이든, 상용 툴이든, 처음부터 끝까지 손으로 직접 하든 — 이 페이지에서 원하는 방식을 그때그때 골라서 바로 시작할 수 있게 모아뒀어요.

2026-08-22 개설 소재 컨펌 → 쇼츠 모음 →
01

지금 이 자리에서 3단계로 시작(수동)

아무 도구도 몰라도 지금 당장 첫 쇼츠 하나를 손으로 완성할 수 있는 최소 경로예요.

  1. 1. 소재 고르기 — 소재 컨펌 페이지나 아래 "쇼츠 모음"에서 쓸 영상 하나를 정한다.
  2. 2. 원본 영상 받기 — 링크를 ssyoutube/SnapInsta 같은 웹 다운로더에 붙여넣거나, 세콤에게 "이거 받아줘"라고 텔레그램으로 보낸다.
  3. 3. 편집하기 — 이미 설치된 Adobe Premiere Pro에서 자르고 자막 붙이고 더빙까지 직접(또는 프리미어의 텍스트 음성변환 기능 사용) — 자동화를 하나도 안 써도 됨.
02

세콤 반자동 경로 — 부품만 자동, 편집은 내가

더빙(TTS) 자동 생성무료 · 즉시 사용 가능

대본만 쓰면 목소리 파일이 나온다. python scripts\secom_shorts_tts.py "대본 텍스트" 출력.mp3

세로 변환 + 더빙 자동 합성무료 · 즉시 사용 가능

원본 영상 + 더빙 mp3를 넣으면 1080×1920 세로 영상으로 자동 합성. python scripts\secom_shorts_render.py 원본.mp4 더빙.mp3 출력.mp4 — 여기서 멈추고 나머지(자막·컷 타이밍)는 프리미어에서 마무리해도 됨.

원본 영상 다운로드설치됨 · 세콤이 대신 실행

유튜브/인스타 링크를 세콤에게 텔레그램으로 보내면 secom_shorts_download.py로 받아둔다.

03

상용 완전자동 툴 — 구독하고 바로 쓰기

직접 조립하지 않고 처음부터 끝까지(소재 선택 힌트+자막+세로 리프레임) 한 번에 해주는 툴. 지난 리서치 결과.

  • Opus Clip — 롱폼/링크 → 하이라이트 자동 감지 → 세로 쇼츠, 이 카테고리 표준
  • Vizard.ai — Opus Clip과 유사, 가격/UI 차이
  • Klap — 동일 카테고리 대안
04

완전 무인(구독료 없이) — 셀프호스팅

노션 트리거부터 업로드까지 사람 개입 없이 돌리고 싶을 때. 직접 새로 짜는 대신 이미 있는 오픈소스를 가져다 쓰는 쪽을 권장.

  • Autotube — n8n 기반, Docker 셀프호스팅, 무료, 노션 연동 가능
  • AI-Youtube-Shorts-Generator — Gemini + Edge-TTS + FFmpeg, 세콤 반자동 경로와 부품 동일
