35Closer Timer 사용 가이드

이 앱을 처음 보는 사람도 화면을 눌러가며 이해할 수 있게 — 전문 용어 없이, 무슨 화면이 뜨고 뭘 누르면 뭐가 되는지 하나씩.

v1.0.0개정판 1
01

개요 — 이 앱은 무엇을 위한 것인가

macOS용 원형 카운트다운 타이머 + 전원 관리 앱. 타이머 종료 시 Sleep/Restart/Shut down/Just notify 중 하나를 실행하고, 무입력 시간 기반 자동 절전(autoIdle)과 화면/시스템 절전 방지(keepAwake)를 제공한다.

전원 진단 기능으로 macOS의 절전 타이머·최근 절전 사유·OS 레벨 전원 예약(pmset)을 한 화면에서 확인/조정할 수 있고, 이 세션에서 Claude Code 사용 이력을 3개월치 로그로 남겨 현장(로컬)/원격 세션을 구분하고 사용량 한도 도달 시 안전하게 절전시키는 기능도 갖고 있다.

02

핵심 사용 흐름

1타이머 설정 및 시작

홈 화면에서 시간을 정하고 시작하면 원형으로 카운트다운된다.

  1. 홈 화면에서 시간을 설정한다.
  2. 종료 시 동작(Sleep/Restart/Shut down/알림만)을 고른다.
2자동 절전 / 절전 방지

autoIdle은 N시간 무입력 시 자동 절전(Claude/Codex 활동 중이면 보류), keepAwake는 절전을 방지한다.

  1. 설정에서 autoIdle 임계 시간을 정한다.
  2. keepAwake로 원하는 강도의 절전 방지를 켠다.
3전원 진단

홈 화면 "전원 진단"에서 pmset 절전 타이머, 실제 절전 사유 로그, OS 레벨 반복/일회성 전원 예약을 본다.

  1. 관리자 암호 확인 후 pmset 절전 타이머를 직접 조정할 수 있다.
  2. "왜 자꾸 절전모드로 들어가"류 문제는 여기서 먼저 확인한다.
4Claude 세션 로그 확인

어떤 프롬프트를, 언제, 어디서(현장/원격) 보냈고 어떤 도구를 썼는지 3개월치 기록을 본다.

  1. 로그 항목마다 현장(파란색)/원격(보라색) 배지가 붙는다.
  2. 사용량/속도 제한 경고가 감지되면 리마인더가 생기고, 실제 유휴 시에만 안전하게 절전된다.
5리마인더 및 Claude 계정 전환

자리에 돌아왔을 때/앱 실행 시 뜨는 대기 리마인더, 여러 Claude 계정 프로필 전환.

  1. 리마인더 시트에서 복사-붙여넣기용 본문을 바로 복사한다.
