4VPN Blocker 사용 가이드

이 앱을 처음 보는 사람도 화면을 눌러가며 이해할 수 있게 — 전문 용어 없이, 무슨 화면이 뜨고 뭘 누르면 뭐가 되는지 하나씩.

v1.0.6개정판 1
01

개요 — 이 앱은 무엇을 위한 것인가

macOS용 자기통제 차단 앱(SwiftUI, 코드명 VeliMac). 단순 사이트 목록이 아니라 3중 구조로 막는다 — ①/etc/hosts DNS 레벨 차단(전 브라우저 동시 적용), ②브라우저 확장(Chrome·Firefox·Safari, 키워드/유튜브 채널·영상·검색결과 단위 정밀 차단), ③Firefox DoH 무력화(우회용 DNS 서버 자체를 막음). 그리고 차단 자체를 우회 못 하게 막는 계층이 따로 있다 — 강제 종료·확장 삭제·스케줄 즉시 변경·앱 삭제 시도까지 전부 막혀 있다. 이게 이 앱의 진짜 핵심이다: 의지가 약해지는 순간에도 못 풀게 설계됐다.

02

핵심 사용 흐름

1우회 자체가 막혀 있다 — 이 앱의 진짜 핵심 기능

직접 실측 확인된 것만 정리 — 순간적인 충동으로는 절대 못 끈다.

  1. 강제 종료(⌘Q·Dock Quit) 자체가 차단됨(ExitKeepAliveService) — 그래도 강제로 죽여도 워치독이 3초 안에 자동 재실행하고, hosts 차단은 앱이 죽어있는 그 짧은 순간에도 유지된다(launchd keepalive).
  2. 브라우저 확장 삭제 방지 — Chrome은 정책으로 강제 설치(force_install)돼 사용자가 확장 관리 화면에서 지울 수 없고, Firefox도 정책으로 잠겨서 자동으로 최신 상태 유지.
  3. 스케줄/규칙 변경도 즉시 안 됨 — 잠금(lock) 상태의 스케줄은 PIN + 냉각 시간(lockCooldownMinutes)이 지나야 해제된다. "지금 당장 풀고 싶다"는 충동이 식을 시간을 강제로 만든다.
  4. AI 에이전트를 통한 우회 시도도 막힘 — Cursor 같은 코딩 AI에게 "이 앱 지워줘/차단 풀어줘"라고 시켜도 안 먹히도록 5중 보호(hooks·rule·AGENT_OVERRIDE·설정 카드)가 걸려 있다.
  5. 임시로 앱을 꺼서 우회하는 것도 안 됨 — hosts 차단은 앱 프로세스와 독립적으로 유지되고, 앱이 내려가 있는 시간 자체가 최소화(3초 워치독)돼 있다.
2말로 걸기 — 채팅 한 줄이 곧 차단 규칙

"매일 아침 10시 유튜브 막아줘"처럼 자연어로 말하면 파싱→미리보기→확인→적용 4단계를 거쳐 실제 스케줄이 된다. 확인 없이는 절대 적용되지 않는다.

  1. "매일 아침 10시 유튜브 막아줘" → 매일 10:00부터 24:00까지 스트리밍 카테고리 차단 스케줄로 자동 변환.
  2. "인스타는 10분 보면 30분 잠기게 하루 40분만" → 세션 10분 제한 + 쿨다운 30분 + 일일 총량 40분 제한을 한 번에 설정.
  3. "평일 오전 9시부터 오후 6시까지 sns 막아줘" → 월~금 09:00~18:00 SNS 카테고리 차단.
  4. 로컬 파서가 먼저 처리하고, 못 알아들을 때만 AI로 폴백 — 매번 API를 부르지 않아 비용이 거의 안 든다.
3검색결과·이미지·유튜브까지 — 링크 하나만 안 막는다

차단 대상이 사이트 하나가 아니라, 그 사이트를 찾아가는 경로(검색결과·이미지·추천 피드) 자체를 막는다.

  1. 구글 등 검색결과 페이지(SERP)에도 키워드 규칙이 적용돼, 차단 대상이 검색결과 목록 자체에서 안 보이게 걸러진다(실사고로 검증된 실제 동작 — 규칙에 없는 사이트까지 과하게 가려진 사건이 있었을 정도로 강하게 작동).
  2. 유튜브는 채널(channelURL)·영상(videoURL) 단위로 차단 가능 — 차단된 채널은 검색결과·홈피드·추천 미리보기 카드에서도 숨겨진다(썸네일·제목까지 안 보임, 클릭 후 차단이 아니라 애초에 안 뜸).
  3. 게임/성인 등 미리 만들어진 대량 프리셋 팩(수백 개 단위)에도 동일하게 적용.
4프리셋 팩 — 하나 눌러서 수백 개를 한 번에

직접 하나씩 입력할 필요 없이, 미리 만들어진 대량 차단 팩을 스케줄에 연결하기만 하면 된다.

  1. 성인 사이트 + YouTube 통합팩 — 약 585개 항목.
  2. 불법 웹툰 사이트팩 — 41개 항목.
  3. 게임 팩 — 400개 항목(유튜브 게임 채널 200 + 게임 사이트 200).
  4. 스케줄 편집 화면에서 "프리셋 팩 연결" 한 번이면 끝.
5통합 규칙 입력 — 한 칸에 아무거나 붙여넣기

URL이든 키워드든 유튜브 채널이든, 종류를 고를 필요 없이 붙여넣으면 자동으로 알맞은 규칙으로 분류된다.

  1. 도메인을 붙여넣으면 host 규칙으로, 단어를 입력하면 keyword 규칙으로 자동 인식.
  2. 숫자로 우회한 IP나 서브도메인 변형까지 같은 규칙으로 확장 매칭.
03

화면별 사용법 — 빠른 레퍼런스

규칙(Rules) 화면

도메인·키워드·채널 규칙을 직접 추가/편집. 통합 입력창 지원.

스케줄(Schedules) 화면

요일·시간대별 차단 스케줄 설정, 프리셋 팩 연결, 채팅 입력창, 잠금(PIN+냉각시간) 설정.

채팅 스케줄 입력 카드

자연어 명령 → 파싱 미리보기 → 확인 후 적용.

진단(Diagnostics) 화면

hosts 적용 상태, Firefox DoH 설정 상태, 확장 활성화·잠금 상태 점검.

설정(Settings) 화면

잠금 PIN, 백업/복원, 앱 버전·확장 버전 동기화 상태.
