01

검토 요약 (0/3 통과, 2026-08-10)

클로이 박이 VIVID 개인 브랜딩 자산(포트폴리오 웹, 명함, 개발자명 일관성, 반응형 비율)을 검토했습니다. 격려가 아니라 진단입니다.

  • ❌ 포트폴리오 웹 — about/ CONTACT 섹션에 실제 휴대폰 번호·학교 이메일 노출 확인. 사용자 확인 후 보류(직접 수정 예정, 클로이 박 추가 조치 없음).
  • ❌ 명함 디자인 — 정의를 "about/로 연결되는 디지털 프로필 카드/QR"로 확정(2026-08-10, 이전엔 미정의). 파일시스템 전체 검색 결과 0건 — 시작 전.
  • ✅ 모바일/데스크탑 반응형 비율 — 375px(모바일)/768px(태블릿)/1280px(데스크탑) 3개 뷰포트에서 허브 루트(/)와 about/ 페이지 실측. 페이지 레벨 가로 스크롤 없음(docScrollWidth ≤ viewport 전 구간). 허브의 '앱별로 보기'·'어떻게 이어지나' 캐러셀은 overflow-x:auto + flex-wrap:nowrap로 의도된 가로 스크롤(버그 아님). 통과.
  • ⬜ 개발자명 일관성 — about/ 안에서는 "김근후"로 일관됨(title/메타/h1/footer/CONTACT 전부 확인). "노드"(브런치 필명)·"Kaito Ren"(ArtStation 필명)은 개발자명이 아니라 실제 외부 플랫폼 계정 자체의 필명이라 대상에서 제외. 실제 스토어(Chrome 웹스토어/Partner Center) 게시자명과의 대조는 접근 권한이 없어 계속 보류.

반응형 실측 데이터

이 세션의 Browser 패널이 화면에 열려있지 않아 이미지 스크린샷은 못 찍었고, JS로 실측한 수치를 그대로 남깁니다.

  • 허브 루트(/) 375px: viewport 375 / docScrollWidth 375 / overflow 없음
  • 허브 루트(/) 768px: viewport 768 / docScrollWidth 753 / overflow 없음
  • 허브 루트(/) 1280px: viewport 1280 / docScrollWidth 1265 / overflow 없음
  • about/ 375px: viewport 375 / docScrollWidth 375 / overflow 없음
  • about/ 1280px: viewport 1280 / docScrollWidth 1265 / overflow 없음, 본문 max-width 700px
