4VPN Blocker 사용 가이드

이 앱을 처음 보는 사람도 화면을 눌러가며 이해할 수 있게 — 전문 용어 없이, 무슨 화면이 뜨고 뭘 누르면 뭐가 되는지 하나씩.

v2.0.0개정판 1
01

개요 — 이 앱은 무엇을 위한 것인가

개인 자기통제용 웹사이트/앱 차단기. macOS 네이티브 앱(코드명 "VeliMac")과 Chrome·Firefox·Safari 브라우저 확장을 함께 써서, 어느 브라우저를 열어도 같은 차단 규칙이 적용된다. 도메인·키워드·프리메이드 팩(성인 콘텐츠 차단팩 등) 단위로 규칙을 정하고, 시간대/요일 스케줄이나 자연어 채팅 명령으로 차단 기간을 정할 수 있다.

Windows 포팅과 macOS·iOS·Windows 간 GitHub 저장소 기반 동기화도 설계·진행 중이다.

02

핵심 사용 흐름

1차단 규칙 추가

통합 입력창에 URL/키워드를 붙여넣거나 프리메이드 팩을 선택하면 자동으로 알맞은 규칙 종류로 분류된다.

  1. URL을 붙여넣으면 도메인 규칙으로, 단어를 입력하면 키워드 규칙으로 자동 인식.
  2. 성인 콘텐츠·게임 등 미리 만들어진 차단 팩을 통째로 적용 가능.
2스케줄 설정

시간대/요일 반복 차단이나 "7일간 차단" 같은 1회성 임시 차단을 정한다.

  1. 일반 스케줄 편집기에서 시간대·요일을 지정.
  2. 자연어 채팅으로 "유튜브 7일간 차단"처럼 말해서 같은 스케줄 엔진에 바로 반영 가능.
3브라우저 확장 활성화

Chrome/Firefox/Safari 각각에 확장을 설치해야 실제로 그 브라우저에서도 차단이 걸린다.

  1. 브라우저별 설치 상태를 확인하고, 비활성 상태면 안내를 따라 재활성화.
4기기 간 동기화

macOS·iOS·Windows 앱 간 차단 목록/스케줄을 공유 GitHub 저장소를 통해 맞춘다(설계 진행 중).

    03

    화면별 사용법 — 빠른 레퍼런스

    macOS 앱 (VeliMac)

    규칙/스케줄 편집, 전체 현황 확인 — SwiftUI 네이티브 앱.

    Chrome 확장

    브라우저 단에서 실제 차단을 집행.

    Firefox 확장

    서명된 XPI로 배포, Chrome과 동일한 차단 모델.

    Safari 확장

    iOS/macOS Safari Web Extension.

    채팅형 스케줄 입력

    자연어로 차단 기간/일일 사용량 상한을 명령.
