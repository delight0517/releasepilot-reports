이 앱을 처음 보는 사람도 화면을 눌러가며 이해할 수 있게 — 전문 용어 없이, 무슨 화면이 뜨고 뭘 누르면 뭐가 되는지 하나씩.

v0.5.0개정판 2 — 각 단계 펼치기 + 앞으로 나올 기능 추가
01

개요 — 이 앱은 무엇을 위한 것인가

스마트폰 게임 앱을 만들었으면, 그걸 실제로 앱스토어에 올리기까지 해야 할 귀찮은 서류 작업이 많다 — 이 앱은 그 서류 작업을 최대한 대신 해주는 비서다.

앱 폴더를 넣으면 앱을 읽어서 분석해주고, 스토어에 올릴 설명글을 자동으로 만들어주고, 실제로 스토어 사이트를 열어 제출하는 순서까지 같이 따라가 준다. 로그인이나 최종 제출처럼 실수하면 안 되는 부분은 항상 사람이 직접 누르게 되어 있다 — 앱이 마음대로 결제하거나 제출해버리지 않는다.

02

핵심 사용 흐름 — 눌러서 하나씩 펼쳐보세요

1 앱 등록하기

맨 처음 화면 — 여기다 내 앱 폴더를 갖다 놓으면 끝.

이 화면은 이렇게 생겼어요
앱 보관함
여기에 폴더를 끌어다 놓으세요 (또는 "폴더 추가" 버튼)
📱 내가 만든 게임 A — 등록됨
📱 내가 만든 게임 B — 진행 중
이렇게 쓰면 돼요
  1. 컴퓨터에서 내 앱 프로젝트가 들어있는 폴더를 찾는다.
  2. 그 폴더를 화면 위로 끌어다 놓거나, "폴더 추가" 버튼을 눌러 고른다.
  3. 한 번 등록하면 없어지지 않는다 — 나중에 다시 열려면 목록에서 카드만 누르면 됨.
2 "진행해" 누르기 — 내 앱 점검받기

등록한 앱을 열면 나오는 화면 — 버튼 하나로 앱을 대신 읽어봐 준다.

이 화면은 이렇게 생겼어요
내 앱 점검
지금 이 앱: 게임 A
진행해
✅ 요약: 습관 기록 카드 게임입니다
⚠️ 빠진 것: 개인정보처리방침 링크
이렇게 쓰면 돼요
  1. "진행해" 버튼을 누른다.
  2. 컴퓨터에 이미 Claude라는 프로그램이 깔려 있으면, 자동으로 내 앱 코드를 읽고 정리해준다.
  3. 없으면 "이 글을 복사해서 붙여넣어 주세요"라는 안내가 나온다 — 시키는 대로 복사→붙여넣기만 하면 됨.
  4. 결과로 "이 앱이 뭘 하는지", "뭐가 빠졌는지", "다음에 뭘 해야 하는지"를 보여준다.
3 Draft Studio — 스토어에 올릴 글 만들기

앱스토어/플레이스토어에 필요한 설명글·이름·키워드를 자동으로 초안 잡아주는 화면.

이 화면은 이렇게 생겼어요
스토어 제출 준비
앱 이름: 게임 A
한 줄 소개: 매일 기록하며 성장하는 습관 게임
⚠️ 아직 못 채운 칸: 2개
전체 복사
이렇게 쓰면 돼요
  1. 앱이 이미 채워둔 글들을 훑어보고, 마음에 안 들면 직접 고친다.
  2. 빨간 표시가 있는 칸은 스토어가 꼭 요구하는 필수 칸이라 반드시 채워야 한다.
  3. 다 채우면 "복사" 버튼으로 앱스토어/플레이스토어 사이트에 그대로 붙여넣을 수 있다.
4 (선택) 마케팅 감각 게임 · 계산기

🎯 아이콘 — "얼마나 광고하면 몇 명이 설치할까"를 실제 공식으로 미리 가늠해보는 화면.

이 화면은 이렇게 생겼어요
마케팅 감각 게임
1막. 광고를 넓게 뿌릴까, 좁게 뿌릴까?
선택지 A: 넓게 뿌리기
선택지 B: 좁게 뿌리기
→ 결과: 클릭 수, 왜 그런지 설명
이렇게 쓰면 돼요
  1. 앱 카드의 🎯 아이콘을 누른다.
  2. "이야기 모드"에서는 선택지를 고르면 실제 광고 이론에 따른 결과를 바로 보여준다 — 게임처럼 재미있게 배우는 코너.
  3. "내 앱에 적용" 탭에서는 내 예산·목표 숫자를 직접 넣어서 예상 설치 수를 계산해볼 수 있다.
5 (선택) 전략 리포트

📊 아이콘 — "어느 나라, 어떤 사람들에게 먼저 보여줄까"를 정리해주는 보고서 서랍.

이 화면은 이렇게 생겼어요
전략 리포트 보관함
📄 지역·타겟 전략 (v1, 2026-08-01)
📄 사용법 가이드 (v1, 개정 2)
열기
이렇게 쓰면 돼요
  1. 앱 카드의 📊 아이콘을 누르면 이제까지 만든 보고서 목록이 나온다.
  2. "열기"를 누르면 브라우저로 그 보고서가 열린다 — 지금 보고 있는 이 문서도 바로 여기 저장된 것.
  3. 더 이상 필요 없으면 "삭제"로 지울 수 있다.
6 출시 진행 시작

준비가 다 끝나면(칸이 전부 초록불이면) 나타나는 마지막 버튼 — 실제 제출 사이트로 데려다준다.

이 화면은 이렇게 생겼어요
출시 진행
① 콘솔 열기 → ② 로그인 대기 → ③ 제출 진행 → ④ 완료
지금 단계: ② 로그인 대기 중
로그인 완료했어요
이렇게 쓰면 돼요
  1. "App Store Connect 제출 진행" 또는 "Play Console 제출 진행" 버튼을 누른다.
  2. 앱이 브라우저를 열어 실제 스토어 로그인 페이지로 데려간다.
  3. 로그인은 내가 직접 한다 — 다 하고 나면 "로그인 완료" 버튼을 눌러 앱에게 알려준다.
  4. 실제로 스토어에 제출까지 마치면 "제출 완료" 버튼을 누른다 — 이것도 앱이 대신 눌러주지 않는다, 항상 내가 직접.
  5. 완료를 누르면 처음 화면 카드에 "완료" 표시가 붙는다.
7 반려됐을 때 다시 고치기앞으로 추가

스토어 심사에서 반려당하면, 그 사유를 넣어서 다시 점검받는 기능 — 아직 안 만들어짐.

이 화면은 이렇게 생겼어요
반려 사유 입력 (예정)
스토어가 보낸 반려 사유를 여기 붙여넣으세요
다시 점검하기
이렇게 쓰면 돼요
  1. 스토어에서 온 반려 이메일 내용을 그대로 복사해서 넣는다.
  2. 앱이 그 내용을 보고 "진행해"(2번) 단계를 자동으로 다시 돌려준다.
  3. 뭐가 문제였는지, 뭘 고쳐야 하는지 다시 정리해서 보여준다.
8 스토어 화면 자동으로 채우기앞으로 추가

지금은 "복사해서 붙여넣기"만 되는데, 나중엔 앱이 브라우저에서 직접 칸을 채워주는 것까지 하려고 함 — 아직 안 만들어짐.

이 화면은 이렇게 생겼어요
자동 입력 (예정)
브라우저에서 자동으로 칸이 채워지는 중...
⚠️ 결제·최종 제출 버튼은 여전히 사람이 직접 누름
이렇게 쓰면 돼요
  1. 지금처럼 복사·붙여넣기 하지 않아도, 앱이 브라우저의 빈 칸을 알아서 채워준다.
  2. 단, 돈이 오가거나 되돌릴 수 없는 버튼은 여전히 사람이 직접 누른다 — 이 원칙은 앞으로도 안 바뀜.
9 여러 앱 한 번에 관리하기 / 문제 생기면 바로 알기앞으로 추가

앱을 여러 개 등록했을 때 한 번에 점검하고, 뭔가 잘못됐을 때 바로 알려주는 기능 — 아직 안 만들어짐.

이 화면은 이렇게 생겼어요
한눈에 보기 (예정)
게임 A — 정상
게임 B — ⚠️ 오류 발생
이렇게 쓰면 돼요
  1. 등록한 앱이 많아지면, 한 화면에서 전체 상태를 한눈에 볼 수 있게 된다.
  2. 뭔가 실패하면 조용히 넘어가지 않고 바로 표시해준다.
