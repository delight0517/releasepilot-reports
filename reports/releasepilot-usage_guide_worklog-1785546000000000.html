01

개요 — 이 앱은 무엇을 위한 것인가

앱 폴더를 드롭하고, 진행해 누르고, 복붙하고, 출시 시작을 누르는 것 — App Store/Play Console 출시 준비의 반복 작업을 최소화하는 게 이 앱의 유일한 목적이다.

코드네임 ReleasePilot, 실제 이름은 대화에서 "23 앱 데브"/"23AppdeveloperReleaser". Windows의 자매 앱 LaunchPad.App과 사실상 같은 제품 — ios/android 트랙은 이 Flutter 앱이, 나머지 트랙(chrome/firefox/macos)은 Windows LaunchPad.App이 담당한다.

02

핵심 사용 흐름

앱 등록

App Vault(첫 화면)에 앱 프로젝트 폴더를 드래그하거나 "앱 폴더 추가"로 선택 — 영구 등록됨.

"진행해" — 프로젝트 분석

등록한 앱 카드를 열면 Project Analysis 화면으로 이동 — "진행해" 버튼을 누르면 로컬 Claude CLI가 있으면 자동 분석, 없으면 프롬프트 복사 + 수동 답변 붙여넣기.

Draft Studio — MVP 패키지

분석 통과 시 자동으로(또는 수동으로) Draft Studio로 이동 — App Store/Play Console에 바로 복붙 가능한 메타데이터 패키지 생성, 필수 필드 누락 시 제출 차단.

(선택) 마케팅 게임 · CTR 계산기

🎯 아이콘으로 진입 — 실제 마케팅 이론 기반 스토리 모드 + 내 앱 수치 계산기.

(선택) 전략 리포트

📊 아이콘으로 진입 — 지역/타겟/CTR 전략, 성장 배수 법칙, 미래 가능성, 법적 리스크를 담은 리포트 보관함. 이 문서 자체도 여기 저장된다.

출시 진행 시작

MVP 체크리스트가 초록불이면 뜨는 버튼 — App Store Connect/Play Console을 열고 콘솔 열기→로그인 대기→제출 진행→완료 4단계를 추적. 로그인/제출은 항상 사람이 직접 확인.

03

화면별 사용법

App Vault (첫 화면)

등록된 앱 목록, 상태 배지(등록됨/분석중/위험발견/준비완료/진행중/완료/반려), 각 카드에 🎯(마케팅게임)/📊(리포트) 아이콘.

Project Analysis

"진행해" 버튼, 분석 결과 카드(요약/위험항목/누락정보/다음할일), 통과 시 자동으로 Draft Studio 이동.

Draft Studio (MVP 패키지)

필드별 편집, 스토어별 복붙 패키지, 체크리스트가 초록불이면 "출시 진행 시작" 버튼 노출.

마케팅 감각 게임

스토리 모드(5막) / 내 앱에 적용(실시간 계산기) 탭.

전략 리포트 보관함

프로젝트별 리포트 목록, 버전·개정판·의도 표시, 열기/삭제.

Automation Run (출시 진행)

단계 인디케이터 + 실시간 로그, "로그인 완료"/"제출 완료" 버튼(항상 사람이 누름).
