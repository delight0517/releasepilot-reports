4VPN Blocker 사용 가이드

이 앱을 처음 보는 사람도 화면을 눌러가며 이해할 수 있게 — 전문 용어 없이, 무슨 화면이 뜨고 뭘 누르면 뭐가 되는지 하나씩.

v1.0.6개정판 1
01

개요 — 이 앱은 무엇을 위한 것인가

macOS용 자기통제 차단 앱(SwiftUI, 코드명 VeliMac). 한 줄 요약이 아니라 실제로 3중 구조로 막는다 — ①/etc/hosts DNS 레벨 차단(전 브라우저에 동시 적용), ②브라우저 확장(Chrome·Firefox·Safari, 키워드/유튜브 채널·영상 단위 정밀 차단), ③Firefox DoH 무력화(정책으로 강제해 우회 DNS 서버 자체를 막음). 단순 사이트 목록 하나 들고 있는 게 아니라, 우회 경로 하나하나를 실제로 틀어막는 구조로 설계돼 있다.

02

핵심 사용 흐름

1말로 걸기 — 채팅 한 줄이 곧 차단 규칙

"매일 아침 10시 유튜브 막아줘"처럼 자연어로 말하면 파싱→미리보기→확인→적용 4단계를 거쳐 실제 스케줄이 된다. 확인 없이는 절대 적용되지 않는다.

  1. "매일 아침 10시 유튜브 막아줘" → 매일 10:00부터 24:00까지 스트리밍 카테고리 차단 스케줄로 자동 변환.
  2. "인스타는 10분 보면 30분 잠기게 하루 40분만" → 세션 10분 제한 + 쿨다운 30분 + 일일 총량 40분 제한을 한 번에 설정.
  3. "평일 오전 9시부터 오후 6시까지 sns 막아줘" → 월~금 09:00~18:00 SNS 카테고리 차단.
  4. 로컬 파서가 먼저 처리하고, 못 알아들을 때만 AI로 폴백 — 매번 API를 부르지 않아 비용이 거의 안 든다.
2프리셋 팩 — 하나 눌러서 수백 개를 한 번에

직접 하나씩 입력할 필요 없이, 미리 만들어진 대량 차단 팩을 스케줄에 연결하기만 하면 된다.

  1. 성인 사이트 + YouTube 통합팩 — 약 585개 항목(사이트 200 + 커뮤니티 링크 목록 두 종 185 + 유튜브 채널 200을 병합).
  2. 불법 웹툰 사이트팩 — 41개 항목.
  3. 게임 팩 — 400개 항목(유튜브 게임 채널 200 + 게임 사이트 200).
  4. 스케줄 편집 화면에서 "프리셋 팩 연결" 한 번이면 끝 — 팩은 계속 갱신되고, 연결된 스케줄에도 자동 반영된다.
3통합 규칙 입력 — 한 칸에 아무거나 붙여넣기

URL이든 키워드든 유튜브 채널이든, 종류를 고를 필요 없이 붙여넣으면 자동으로 알맞은 규칙으로 분류된다.

  1. 도메인을 붙여넣으면 host 규칙으로, 단어를 입력하면 keyword 규칙으로 자동 인식.
  2. 유튜브 채널/영상 링크는 channelURL·videoURL로 각각 분류돼 유튜브 확장 차단에 연결.
  3. 숫자로 우회한 IP나 서브도메인 변형까지 같은 규칙으로 확장 매칭.
4브라우저 3종 동시 방어

Chrome·Firefox·Safari 확장이 각각 설치되고, Firefox는 DoH(우회용 DNS)까지 정책으로 잠근다.

  1. 확장은 Firefox 소스 하나를 원본으로 두고 앱이 Chrome/Safari용으로 자동 변환해 내보낸다 — 세 브라우저가 항상 같은 규칙을 쓴다.
  2. Firefox는 DNS-over-HTTPS를 정책으로 강제 비활성화해, hosts 차단을 무력화하는 우회로 자체를 막는다.
5동기화·백업·잠금

설정을 스냅샷으로 백업/복원할 수 있고, 전역 잠금 모드(PIN)로 스스로도 쉽게 풀 수 없게 걸어둘 수 있다.

    03

    화면별 사용법 — 빠른 레퍼런스

    규칙(Rules) 화면

    도메인·키워드·채널 규칙을 직접 추가/편집. 통합 입력창 지원.

    스케줄(Schedules) 화면

    요일·시간대별 차단 스케줄 설정, 프리셋 팩 연결, 채팅 입력창.

    채팅 스케줄 입력 카드

    자연어 명령 → 파싱 미리보기 → 확인 후 적용.

    진단(Diagnostics) 화면

    hosts 적용 상태, Firefox DoH 설정 상태, 확장 활성화 여부 점검.

    설정(Settings) 화면

    잠금 PIN, 백업/복원, 앱 버전·확장 버전 동기화 상태.
