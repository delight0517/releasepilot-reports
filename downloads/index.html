등록된 앱의 버전·진행률과, 지금 이 순간 실제로 받아 설치할 수 있는지를 플랫폼별로 정직하게 보여줍니다.

정직 고지 — 지금은 어떤 앱도 서명·공증·스토어 심사를 마치지 않았습니다.
  • 🍎 macOS: Apple Developer Program(연 $99) 서명·공증 전까지는 Gatekeeper가 막습니다.
  • 🪟 Windows: 코드서명 인증서 전까지는 SmartScreen 경고가 뜹니다(실행 자체는 가능).
  • 📱 iOS: 웹사이트 직접 설치는 애플 정책상 불가능 — TestFlight 또는 App Store 출시가 필요합니다.
  • 🤖 Android: "출처를 알 수 없는 앱" 허용 시 APK 직접 설치가 실제로 가능합니다.
🗂️ 전체 워크스페이스 통짜 다운로드

이 사이트와 앱 간 동기화 데이터를 저장소 통째로 받을 수 있습니다. GitHub가 만드는 zip이라 별도 파이프라인 없이 항상 최신 상태입니다.

  • 이 허브 웹사이트 전체 (.zip) — 공개 저장소, 누구나 다운로드 가능
  • 앱 간 동기화 데이터 허브 (.zip) — 비공개 저장소라 본인 GitHub 계정으로 로그인 + 접근 권한이 있어야 실제로 받아집니다. 다른 컴퓨터에서 받으려면 그 컴퓨터에서 같은 계정으로 gh auth login 또는 브라우저 로그인이 먼저 필요합니다 — 남이 그냥 받을 수 있다는 뜻이 아닙니다.
