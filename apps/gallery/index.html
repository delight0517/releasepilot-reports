필름을 다루듯 느긋하게 넘겨보는 개인 포트폴리오. 원본 비율 그대로 담습니다.

이 페이지는 반응형 웹으로 iOS Safari에서도 그대로 동작하도록 만들었습니다 — "공유 → 홈 화면에 추가"로 앱처럼 아이콘을 만들어 쓸 수 있습니다. 별도 네이티브 iOS 앱이 필요한지는 아직 확인되지 않았고, 필요성이 분명해지면 그때 다시 판단합니다. (가정 사항 — 문제가 있다면 알려주세요.)

사진 추가는 웹에서 업로드하지 않고, apps/gallery/photos/에 파일을 넣고 apps/gallery/photos.json에 한 줄 추가한 뒤 commit/push로 반영합니다 (rogan 본인 전용 — Claude Code 세션에 "이 사진들 갤러리에 추가해줘"라고 하면 대신 처리).
