이제 사이트 4개를 매일 새로고침하지 마세요

세콤(SECOM) 알바 파인더는 알바몬 · 미디어잡 · 필름메이커스 · 원티드를 직접 돌아다니며, 내 조건에 맞는 공고만 골라서 점수와 함께 텔레그램으로 보내줍니다.

👤 "왜 만들었냐고요? 제가 그 알바생이었으니까요"

개발자 김근후(GeunHu Kim)가 직접 만든 이유 — 세콤은 '취업이 안 돼서'가 아니라 '찾는 방법이 없어서' 헤매는 사람을 위한 도구입니다.

Q. 어떤 문제를 해결하나요?
알바 공고는 사이트마다 흩어져 있습니다. 알바몬에 있고, 미디어잡에 있고, 필름메이커스에 있습니다. 촬영보조 하나 찾으려고 4개 사이트를 매일 새로고침하며 '오늘 내 지역에 올라온 공고 있나' 눈으로 확인하는 게 현실입니다. 세콤은 이 반복을 없앱니다.
Q. 어떻게 동작하나요?
Playwright 브라우저가 4개 사이트를 직접 방문해 공고를 수집하고, 내 프로필 키워드와의 매칭 점수(0~100)를 계산합니다. 지역(대전·세종) 가산점, 재택·원격 가산점, 단기·주말 가산점까지 — 마치 채용 담당자가 이력서를 읽듯 공고를 평가합니다.
Q. 실제로 되나요?
가짜 데모는 없습니다. 아래는 2026년 9월 3일 실제 실행으로 잡아낸 9건의 매칭 결과입니다.

🛠 3단계면 끝 — 누구나 쓸 수 있습니다

개발자가 아니어도 따라 할 수 있습니다. 필요한 건 GitHub 계정과 텔레그램뿐이에요.

코드 받기

git clone https://github.com/delight0517/secom-kr-jobfinder 또는 GitHub 페이지에서 Code → Download ZIP. 그다음 npm install 한 번이면 준비 끝.

내 조건 입력하기 (제일 중요!)

src/albani_crawler.js 맨 위 PROFILE_KEYWORDS에 내가 원하는 걸 넣으세요. '촬영보조', '대전', '재택', '주말'… 이 키워드가 곧 '나'입니다.

실행하고 텔레그램으로 받기

node src/albani_crawler.js 실행 → python3 send_telegram.py 실행. 매칭 공고가 점수순으로 내 텔레그램에 도착합니다. 매일 아침 자동 실행도 설정 가능해요.

💡 다른 구인 앱과 뭐가 다른가요?

🔓 오픈소스, 평생 무료

구독료 없음, '유료 공고 노출' 없음. 코드 전체가 MIT 라이선스로 공개되어 있어 내려받는 순간 내 도구가 됩니다.

🎯 '내 조건'이 곧 검색어

앱의 추천이 아니라 내가 직접 정의한 키워드(지역·직무·시간)로 점수를 매깁니다. 프리랜서 개발자+방송 스텝을 동시에 찾는 복합 프로필도 지원합니다.

📱 텔레그램으로 알림

앱을 켜고 있을 필요가 없습니다. 새 매칭이 생기면 봇이 보내주는 메시지와 HTML 리포트로 확인하면 끝.
