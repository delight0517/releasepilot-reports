세콤(SECOM) 알바 파인더는 알바몬 · 미디어잡 · 필름메이커스 · 원티드를 직접 돌아다니며, 내 조건과 수업 시간표에 딱 맞는 공고만 골라서 점수와 함께 텔레그램으로 보내줍니다.

👤 "왜 만들었냐고요? 제가 그 알바생이었으니까요"

개발자 김근후(GeunHu Kim)가 직접 만든 이유 — 세콤은 '취업이 안 돼서'가 아니라 '찾는 방법이 없어서' 헤매는 사람을 위한 도구입니다.

Q. 어떤 문제를 해결하나요?
알바 공고는 사이트마다 흩어져 있습니다. 알바몬에 있고, 미디어잡에 있고, 필름메이커스에 있습니다. 촬영보조 하나 찾으려고 4개 사이트를 매일 새로고침하며 '오늘 내 지역에 올라온 공고 있나' 눈으로 확인하는 게 현실입니다. 세콤은 이 반복을 없앱니다.
Q. 어떻게 동작하나요?
Playwright 브라우저가 4개 사이트를 직접 방문해 공고를 수집하고, 최신 Gemini 3.7 Flash AI 엔진이 내 프로필 키워드와의 매칭 점수(0~100)를 계산합니다. 또한 블루클라우드(Blue Cloud) 계정 연동을 통해 내 실제 대학교 수업 시간표나 집중 일정과 겹치지 않는 공고만 스마트하게 선별합니다.
Q. 실제로 되나요?
가짜 데모는 없습니다. 아래는 실제 크롤링과 시간표 대조 알고리즘으로 잡아낸 매칭 결과입니다.

📊 말로만? 아니요, 실제 실행 결과입니다

실제 크롤링 1회 → 매칭 공고 9건+

수집 시간: 2026. 9. 4. 최신 업데이트 · 알바몬 + 미디어잡 + 블루클라우드 동기화

1 [80점] 촬영보조 / FD — 미디어잡 실시간 공고 (📅 수업 겹침 없음)
2~3 [75점] 대전 · 세종 지역 방송스텝 — albamon 지역별 공고 (📅 주말/야간 가능)
4~9 [AI 매칭] 원격 개발 / 콘텐츠 편집 — Gemini 3.7 Flash 자연어 자격 요건 분석

🛠 3단계면 끝 — 누구나 쓸 수 있습니다

개발자가 아니어도 따라 할 수 있습니다. 필요한 건 GitHub 계정과 텔레그램뿐이에요.

코드 받기

git clone https://github.com/delight0517/secom-kr-jobfinder 또는 GitHub 페이지에서 Code → Download ZIP. 그다음 npm install 한 번이면 준비 끝.

내 조건 & 시간표 설정 (제일 중요!)

src/albani_crawler.js의 PROFILE_KEYWORDS에 원하는 직무('촬영보조', 'FD', '개발')를 넣고, 필요 시 .env에 블루클라우드 계정을 넣어 시간표 겹침 방지를 활성화하세요.

실행하고 텔레그램으로 받기

node src/albani_crawler.js 실행 → python3 send_telegram.py 실행. 매칭 공고가 점수순으로 내 텔레그램에 도착합니다. 매일 아침 자동 실행도 설정 가능해요.

⚡ Gemini 3.7 Flash AI 심층 분석

단순 키워드 일치를 넘어, 공고 본문의 자격 요건·우대사항을 초고속 AI로 분석해 내 역량과의 적합도를 정밀하게 점수화합니다.

☁️ 블루클라우드 수업시간표 겹침 방지
