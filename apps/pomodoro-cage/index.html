🍅 진짜 포모도로 사이클

25분 집중과 5분 휴식을 자동 반복. 알림이 오면 반드시 쉽니다 — 앉아있는 시간을 강제로 끊어줍니다.

🔄 맥 서버 연동 강제 휴식

같은 Wi-Fi의 개인 맥 서버와만 통신해, 아이폰과 맥의 타이머 상태를 실시간 동기화합니다. 한쪽에서 쉬면 다른 쪽도 쉽니다.

🛡️ 개인정보는 기기에만

모든 타이머 기록은 기기에만 저장되고 외부 서버로 전송되지 않습니다. 개인 맥 서버 통신도 인터넷을 거치지 않습니다.
