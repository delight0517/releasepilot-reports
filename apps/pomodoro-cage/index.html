지키는 것

앱이 말하는 잠금과 실제 명령 처리가 어긋나지 않도록 같은 안전 경로를 사용합니다. 동기화는 오래된 변경과 충돌을 다루는 계약을 갖고 있습니다.

  • 휴식 중 우회 시도는 실제 정책에서 다시 확인
  • 설정과 타이머 상태를 별도로 다루는 동기화 구조
  • 선택 앱 목록·비밀번호는 피드백 진단에서 제외

아직 말하지 않는 것

실기기에서 권한을 받은 iPhone 차단, 외부 앱 차단 성공, 모든 기기의 실시간 동기화는 코드가 있다고 해서 완료가 아닙니다. 확인 전에는 완료라고 부르지 않습니다.

  • iPhone Screen Time 권한과 실제 shield 동작
  • Mac·Windows·iPhone 양방향 실사용 왕복
  • 스토어 공개와 결제·매출 성과
