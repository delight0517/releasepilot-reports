How it works

운영 방식

붙여넣기 한 번이면 끝 — 코스 이름도, 색상도, 질문도 전부 AI가 정합니다.

1

아무거나 던져 넣어요

유튜브 링크 하나, 재생목록·"나중에 볼 동영상" 페이지 통째 복붙, 그냥 텍스트 — 형식 안 가립니다. 링크만 정규식으로 건져내고, 나머지는 AI가 처리해요.

2

AI가 분류·정리해요

기존 코스/유닛에 맞으면 그대로 꽂고, 없으면 이름·테마 색상까지 새로 정합니다. 긴 글(노션 페이지 등)은 개념 단위로 먼저 쪼갠 뒤 분류해요.

3

4단계 질문으로 진짜 이해시켜요

인출(자기 말로 재구성) → 연결(다른 레슨과 엮기) → 적용(새 상황에 판단) → 창조(직접 만들기). 빠른 확인이 필요한 개념은 근거 인용까지 붙는 OX 형식으로도 나와요.

4

간격 반복으로 잊기 직전에 다시

점수가 다음 복습 시점을 직접 결정합니다(SM-2 축약판). 정답이든 오답이든 매번 "정확한 정의 재확인 + 왜 그런지 + 내 답과의 비교" 설명 카드까지 받아요.
