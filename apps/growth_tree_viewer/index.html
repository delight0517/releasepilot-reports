🌳 Growth Tree Viewer

성장 트리 리포트를
iOS에서 읽기 전용으로

이 사이트(releasepilot-reports)에 공개 게시된 growth_tree.json 리포트를 iOS에서 바로 열어보는 뷰어입니다. 로그인도, 업로드도 없습니다 — 이미 게시된 것을 읽기만 합니다. 웹 버전(growth/geunhoo/)과 같은 팔레트·잠금/진행 표시 로직을 그대로 따릅니다.

iOS 설치 페이지 → 다운로드 전체 보기
⚠️ 지금은 등록된 기기 2대에서만 설치됩니다. Apple 개발자 development 서명이라 프로비저닝 프로파일에 등록된 UDID가 아니면 다운로드는 되지만 설치가 실패합니다. App Store 정식 배포가 아닙니다.
What it does

확인된 기능

lib/main.dart 상단 주석과 코드 구조에서 실제로 확인된 것만 적었습니다.

📖

읽기 전용 뷰어

공개 저장소(releasepilot-reports)의 growth_tree.json을 불러와 보여줄 뿐, 편집·업로드 기능은 없습니다.

🔓

로그인 없음

인증 없이 바로 열립니다 — 공개 게시된 리포트를 보는 용도입니다.

🧩

노드 상세 보기

트리의 각 노드(할 일 항목)를 탭하면 왜/무엇을/성공 시 효과/실패 시 비용 같은 상세 정보를 시트로 보여줍니다.

🌐

웹 버전과 동일한 로직

growth/geunhoo/index.html(웹판)과 같은 색상·잠금(선행 조건)·진행률 계산 로직을 그대로 따르도록 만들어졌습니다.
